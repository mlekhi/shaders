# shaders

approved direction: cinematic react gallery teaching coordinates, distance, time, and sampling through real vgpu / wgsl effects.

latest user correction: minimal. remove the essay, hero, decorative thumbnails and large headings. keep a large canvas, four tabs, essential controls, one sentence per scene, and optional source reveal. near-black page, quiet typography, live visuals as the focal point.

coordinates map x/y to red/green with adjustable blue and optional grid. distance thresholds a circle with a field reveal. time animates a radial sine wave with pause, scrub, frequency and grayscale reveal. sampling compares the same image through smooth sampling, quantization and ordered dithering.

keyboard-accessible controls and canvas; reduced motion pauses animation. async initialization cancellation and device-loss reporting; explicit fallback when webgpu cannot initialize. local project only; no backend or deployment.
